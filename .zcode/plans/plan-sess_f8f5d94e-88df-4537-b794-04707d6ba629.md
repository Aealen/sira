# 投资分析工具（资讯收集 + 行情分析 + 模拟盘）实施计划

## 一、总体架构

前后端分离的本地 Web 应用：

- **后端**：Python 3.12（uv 管理）+ FastAPI + SQLAlchemy 2.x（SQLite 存储）+ APScheduler（定时任务）+ akshare/pandas/numpy（数据与分析）
- **前端**：Vue 3 + TypeScript + Vite + Element Plus（后台组件）+ ECharts（K线/收益曲线）+ Pinia + Axios
- **数据存储**：SQLite 单文件 `data/app.db`（零运维），行情/资讯本地缓存
- **实时行情**：前端 5–10 秒轮询后端（免费数据源本身约 3 秒延迟，轮询足够；WebSocket 留作二期）

## 三、核心模块设计

### 1. 数据源层（适配器模式，隔离 akshare 的不稳定性）

抽象接口 `MarketDataSource`：`search / get_quote / get_kline / get_fund_nav / get_valuation_history`，按市场实现：

- **A股/ETF**：akshare（东财/新浪源），实时报价 + 日K + PE/PB 历史
- **场外基金**：akshare 基金净值接口（按日净值申赎，符合真实规则）
- **港美股**：akshare 港美股接口，接口异常时仅降级该市场
- 统一容错：失败重试（指数退避）→ 本地 SQLite 缓存兜底返回最近数据并标注 `stale=true`

### 2. 分析模块（直接实现知识库 docs/02 的公式）

- `indicators.py`：年化波动率（日收益率 std × √250）、最大回撤、夏普比率
- `valuation.py`：当前 PE/PB 在自身历史序列中的分位数，输出 30%/70% 区间判断
- 组合输出"风险评估报告"：用户自设可承受回撤 → 按知识库公式给出参考仓位上限（展示指标，不构成买卖信号）

### 3. 资讯收集模块

- APScheduler 定时抓取财经快讯/新闻（akshare 资讯接口）
- 按知识库的**四层因素框架**关键词规则打标：公司基本面 / 行业动态 / 宏观政策 / 资金情绪，附简单情绪倾向（利好/利空/中性）
- 关联标的识别（新闻中出现的股票代码/名称）

### 4. 模拟盘（进阶版，纯本地虚拟资金，不接真实券商）

- **账户**：初始资金可配置（默认 100 万虚拟），账户净值曲线每日记录
- **下单**：市价单即时成交（场内按实时报价）；场外基金按 T 日净值成交（收盘净值出来后确认份额）
- **费率模拟**：佣金万 2.5（最低 5 元）、卖出印花税万 5、场外基金申购费 0.1%/赎回费按持有期阶梯——全部可配置
- **定投计划**：标的 + 金额 + 频率（周/月），调度器到期自动下单，可暂停/恢复
- **复盘统计**：收益曲线（对比沪深300）、最大回撤、胜率、盈亏比、定投计划执行记录

### 5. API 概要（REST，前缀 /api）

`market/search`、`market/quote/{market}/{code}`、`market/kline/...`；`analysis/risk/...`、`analysis/valuation/...`；`news`（分类筛选分页）；`portfolio/order`（POST 买卖）、`portfolio/overview`、`portfolio/stats`；`plans`（定投 CRUD）

### 6. 前端页面（5 个）

仪表盘（自选报价 + 账户概览 + 要闻）、行情页（搜索 + K线）、分析页（指标卡片 + 估值分位标尺 + 仓位参考）、资讯页（四类 Tab）、模拟盘页（下单面板 + 持仓 + 收益曲线 + 定投管理）

## 四、分阶段实施（每阶段独立可运行验证）

| 阶段 | 内容 | 验证方式 |
|---|---|---|
| M1 | 后端骨架 + 数据源层 + 行情 API；前端骨架 + 行情页 | curl 验证报价/K线接口返回真实数据；页面能搜索看 K 线 |
| M2 | 分析模块 + 分析页 | 单测：用手工可算的构造序列验证指标正确性 |
| M3 | 模拟盘核心 + 模拟盘页 | 单测：买卖资金/份额/费率结算；页面完整走一单 |
| M4 | 资讯收集 + 资讯页 | 抓取后分类打标准确性抽查 |
| M5 | 定投计划 + 复盘统计 | 单测：扣款成交逻辑；收益曲线/回撤计算 |
| M6 | 收尾：启动脚本、README、设计文档归档 | 前后端一键启动验收 |

## 五、测试与验证策略

- **后端 pytest**：重点覆盖指标计算（波动率/MDD/分位数用已知结果的小数据集断言）、交易引擎结算（资金/份额/费率精确到分）、数据源容错（mock 网络失败）
- **前端**：`vite build` 通过 + 每页面手动验收清单
- **数据源**：单测全部 mock，另提供可选 smoke 测试脚本真实调接口

## 六、风险与对策

- akshare 免费接口不稳定 → 适配器隔离 + 重试 + SQLite 缓存兜底（`stale` 标注），坏一个市场不影响其他
- 港美股接口变化 → 同上，按市场降级
- 免费行情约 3 秒延迟 → 对模拟盘与看盘足够，页面标注"行情有延迟，非实时撮合"
