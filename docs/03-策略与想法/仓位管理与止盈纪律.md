# 仓位管理与止盈纪律

> 归档日期：2026-09-22
> 类型：学习笔记（策略与想法）
> 一句话总结：**会买是徒弟，会卖是师傅——卖出必须发生在买入之前就写好的规则里，而不是发生在恐惧或贪婪的当下。**

## 一、仓位管理：买多少，比买什么更早决定

### 1. 用最大回撤倒推仓位上限（承接风险篇）

```
标的仓位上限 ≈ 自己能承受的最大回撤 ÷ 标的历史最大回撤
例：能承受 -20%，某行业基金历史最深 -60% → 该基金仓位 ≤ 1/3
```

先诚实评估自己（睡得着觉为准），再匹配标的，而不是反过来。

### 2. 留子弹原则

- 除非极端低估，**不满仓**：现金/货基 5%–10% 常备；
- 买入分批（如把计划资金分 3–6 份，按月或按跌幅间隔买入），避免"一把梭在山顶"；
- 极端暴跌（如指数 -30% 以上且[估值分位](../02-风险与评估/估值指标：PE、PB与估值分位.md)极低）时，子弹才有意义。

### 3. 金字塔式加减仓（进阶）

- **加仓**：越跌越买且**越买越多倒金字塔**（低估区分批加大），而非越涨越重仓；
- **减仓**：越高越卖且越卖越多，而非涨了舍不得卖。
- 本质：让成本重心始终低于市场重心。

### 4. 单一标的集中度红线

新手建议：单只个股 ≤ 总仓位 10%（甚至暂不碰个股）；单一行业主题 ≤ 20%——个股有[永久损失风险](../02-风险与评估/风险衡量指标：波动、回撤与夏普比率.md)（退市归零），宽基没有。

## 二、止盈：三种主流方法

### 1. 目标收益率法（最简单）

- 设定目标（如年化 15% 或总收益 30%），达到即分批卖出；
- 优点：规则清晰易执行；缺点：目标拍脑袋，牛市里卖飞、熊市里永远达不到；
- 适合：震荡市、心态练手期。

### 2. 估值分位法（定投的黄金搭档）

- [估值分位](../02-风险与评估/估值指标：PE、PB与估值分位.md) > 70% 开始分批卖，每上一档（80%、90%）多卖一档；
- 优点：有内在逻辑（贵了才卖）；缺点：高估可以更高，要接受"卖早了"的可能；
- 适合：指数基金定投的止盈（分位数据正是本项目工具要算的）。

### 3. 回撤止盈法（让利润奔跑）

- 从市值最高点回撤 X%（如 10%–15%）时，卖出锁定利润；
- 优点：牛市不轻易下车，趋势尽头自动离场；缺点：必然把最高点的一部分利润还回去；
- 适合：单边牛市中持有弹性大的标的。

**组合用法**：估值分位法决定"开始止盈的区域"，回撤法决定"离场的时机"，两者可以叠加。

## 三、卖出的三个正当理由（以及一个不正当理由）

**正当理由**：

1. **估值贵了**——价格明显透支未来（分位法）；
2. **逻辑变了**——当初买入的理由消失（基金经理离任、行业逻辑破坏、自己看错了）；
3. **有更好的去处**——确定性更高的机会出现。

**不正当理由**：

- ❌ "跌了，我慌了"——这是把决策权交给了[羊群效应](../01-基础知识/股价的形成机制与羊群效应.md)；除非上述三条之一成立，下跌本身不是卖出理由，反而常常是买入理由（对宽基而言）。

## 四、新手策略误区清单（行为风险的自查表）

| 误区 | 实质 | 对策 |
|---|---|---|
| 频繁交易 | 手续费磨损 + 情绪化决策 | 降低操作频率，季度级检视 |
| 追涨杀跌 | 羊群效应 + 锚定效应 | 买卖规则提前写好 |
| 全仓单票/单行业 | 赌永久损失风险 | 集中度红线 |
| 拿生活费/借的钱投资 | 无风险承受力可言，波动必然变成永久损失 | 只用闲钱 |
| 上杠杆（融资/合约） | 放大一切，包括错误；新手 + 杠杆 = 出局加速器 | 新手阶段零杠杆 |
| "回本我就卖" | 锚定效应，市场不知道你的成本 | 以估值/逻辑为锚，不以成本为锚 |
| 抄底抄在半山腰 | 便宜是分位概念不是跌幅概念 | 分批 + 估值分位确认 |
| 装死不止损/不止盈 | 处置效应（亏了死扛 + 赚了不收） | 规则化卖出 |

## 五、一页纸策略框架（本知识库的整合视图）

```
① 定比例 —— 资产配置（股/债/金/现金，回撤承受力校验）
② 选标的 —— 宽基起步，核心-卫星扩展
③ 买入     —— 定投（可按估值分位智能加减速），分批留子弹
④ 持有     —— 季度检视，再平衡（定时或 ±5% 阈值）
⑤ 卖出     —— 估值分位定区域 + 回撤法定时机，三个正当理由之外不卖
```

纪律的意义：**在策略框架里，没有一个环节依赖"预测市场"**——这正是普通人在[不可预测的短期行情](../01-基础知识/股票与基金价格的影响因素.md)面前的唯一系统性优势。
