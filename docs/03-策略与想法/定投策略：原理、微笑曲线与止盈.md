# 定投策略：原理、微笑曲线与止盈

> 归档日期：2026-09-22
> 类型：学习笔记（策略与想法）
> 一句话总结：**定投赚的不是"择时"的钱，是"波动"的钱——下跌不是定投的敌人，跌了不回来才是。**

## 一、定投是什么

**定期 + 定额**买入某一标的（通常是指数基金），例如每月固定日期投 1000 元，不管涨跌。

它的第一重价值甚至不是收益，而是**纪律**：把"什么时候买、买多少"从情绪手里拿走，交给规则——直接绕开了[羊群效应与追涨杀跌](../01-基础知识/股价的形成机制与羊群效应.md)。

## 二、数学本质：摊薄成本

每期金额固定时，**价格低的月份买到的份额多，价格高的月份买到的份额少**。这使定投的持仓成本低于各期价格的算术平均（"便宜时多买"自动实现）。这与"越跌越买"的逆向操作在数学上是同一件事，但不需要任何主观判断。

## 三、微笑曲线：本项目第一次代码验证（2026-09-22）

**命题**：定投在"先跌后涨"的 V 形路径中表现最好，甚至价格跌回原点仍能盈利。

**模拟设定**：10 期价格路径，每期定投 1000 元，与期初一次性投入等额资金对比：

| 价格路径 | 一次性买入 | 定投 |
|---|---|---|
| 单边上涨（100→150） | **+50.0%** | +23.0% |
| 微笑回原点（100→60→100） | 0.0% | **+27.0%** |
| 微笑更高点（100→60→130） | +30.0% | **+62.1%** |

**结论**：

1. **价格回到原点，定投仍赚 27%**——收益全部来自下跌段积累的低价筹码。这就是"微笑曲线"的数学本质：对定投者而言，**先跌后涨 > 一直涨 > 一直跌**。
2. **单边上涨市中定投跑输一次性买入**——因为后期买入的价格越来越高。定投不是收益最大化策略，它是**降低择时风险**的策略。
3. 由此推出定投真正的敌人：**长期阴跌不回头**（跌了不回来，微笑曲线只画出左半边）。

> 模拟代码路径：会话内 node 脚本，逻辑极简（份额累加 × 期末价 ÷ 总投入），后续可并入工具模块。

## 四、定投的适用边界

| 场景 | 定投表现 |
|---|---|
| 宽基指数基金（长期向上、波动大） | ✅ 最佳适用对象 |
| 先跌后涨 / 长期震荡 | ✅ 微笑曲线生效 |
| 单边牛市 | ⚠️ 跑输一次性买入，但仍然赚钱 |
| 长期阴跌的标的（夕阳行业、差行业基金） | ❌ 越投越亏——**定投救不了坏标的** |
| 波动极小的资产（货币基金、短债） | 无意义，直接买即可 |

**先选对标的，再谈定投**：定投是买入方式，不是选品逻辑。

## 五、不止盈 = 坐过山车

定投最大的坑：成本被摊薄、收益积累起来之后，如果一直不卖，一轮熊市就把浮盈全部还回去（A股历史回撤见[风险衡量指标](../02-风险与评估/风险衡量指标：波动、回撤与夏普比率.md)，宽基也能回撤 50%+）。

所以完整的定投 = **买入纪律 + 止盈纪律**，止盈方法见《[仓位管理与止盈纪律](仓位管理与止盈纪律.md)》。

## 六、智能定投：把估值分位接进来

普通定投每期金额固定；**智能定投**让金额随[估值分位](../02-风险与评估/估值指标：PE、PB与估值分位.md)变化：

- 低分位（< 30%）：加码（如 1.5 倍）
- 中性区（30%–70%）：标准额度
- 高分位（> 70%）：减码甚至暂停，转入止盈流程

本质是把"微笑曲线多积累低价筹码"从被动等待变成主动加速——这也是本项目工具最值得实现的策略模块之一。

## 七、新手落地清单

1. 标的：宽基指数基金起步（沪深300 / 中证500 / 全指类）；
2. 频率与金额：月定投，金额 = 月结余的一部分，**绝不动用应急资金**；
3. 纪律：跌了不减、涨了不加码追（标准版）；或按估值分位加减速（进阶版）；
4. 止盈：开始定投前就写好止盈规则，见专门文档；
5. 检查周期：每季度看一次即可，天天看只会喂养焦虑。
