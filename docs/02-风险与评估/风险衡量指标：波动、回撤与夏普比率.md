# 风险衡量指标：波动、回撤与夏普比率

> 归档日期：2026-09-22
> 类型：学习笔记（风险与评估）
> 一句话总结：**波动率量"日常有多颠"，最大回撤量"最惨亏多少"，夏普比率量"每份颠簸换来多少收益"——新手最先该搞清楚的是自己能承受多大的最大回撤。**

## 一、先分清两种"风险"

"风险"这个词被混用得很厉害，必须先拆开：

| | 波动风险 | 永久损失风险 |
|---|---|---|
| 含义 | 价格上下起伏、账面浮亏浮盈 | 本金永远回不来 |
| 例子 | 指数跌 30% 后几年涨回来 | 公司退市归零；买在泡沫顶一辈子解不了套 |
| 谁在用这个定义 | 学术界（标准差、CAPM） | 价值投资派（巴菲特："风险是本金的永久损失"） |
| 对新手的意义 | 决定你**拿不拿得住** | 决定你**还在不在牌桌** |

一个重要的自我认知：新手最大的风险源往往不是市场，而是**自己的行为**——追高、恐慌割肉、重仓单票。指标是死的，行为才是活的风险。

## 二、波动率（Volatility）

**定义**：收益率序列的标准差。日常使用的是**年化波动率** = 日收益率标准差 × √250（A股一年约 250 个交易日）。

**直觉**：年化波动率 25% ≈ "典型的一年里上下摆动百分之二十几"。

**缺点**：上涨的颠簸和下跌的颠簸被同等计入——大涨的年份波动率也高，但没人会抱怨。只惩罚下跌的版本叫**索提诺比率**的思路（见下文）。

## 三、最大回撤（Max Drawdown）——新手最重要的数字

**定义**：历史上从**最高点到之后最低点**的最大跌幅。计算口径：`MDD = (区间最低价 − 区间最高价) / 区间最高价`。

**它回答的问题是**："如果我买在最倒霉的时点，最多亏多少？"

**体感数据（历史极值，供校准预期）**：

- 沪深300：2008 年最大回撤约 **-70%**（2007 高点至 2008 低点）。
- 创业板指：2015–2018 年最大回撤约 **-70%**。
- 偏股混合型基金指数历史上也有超过 -50% 的回撤区间。

**为什么它比波动率重要**：你能不能拿住一只标的，取决于它的最大回撤你**承受得起承受不起**，而不是平均收益好不好看。一个年均 15% 但中途会回撤 50% 的策略，绝大多数人会在半途割肉，把"纸面收益"变成"实际亏损"。

## 四、夏普比率（Sharpe Ratio）

**公式**：`夏普 = (年化收益率 − 无风险利率) / 年化波动率`

无风险利率通常取十年期国债收益率（或货基收益率）。

**含义**：每承担一份波动，换来多少**超额收益**。它是比较两只基金 / 两个策略的**公平尺子**——收益高的不一定好，可能只是靠承担更高波动换来的。

**粗略经验**（因市场与周期而异，非铁律）：长期 > 1 算不错，> 2 算优秀。

**盲区**：只看总波动，不区分上行下行；对"偶尔巨亏、平时平稳"的策略（尾部风险）会高估其优劣——只惩罚下行波动的变体叫**索提诺比率（Sortino Ratio）**。

## 五、三指标对比

| 指标 | 回答的问题 | 适合谁用 |
|---|---|---|
| 波动率 | 日常颠簸有多大 | 组合监控、夏普的计算原料 |
| 最大回撤 | 最倒霉会亏多少 | **所有人，尤其是定投/长期持有者** |
| 夏普比率 | 每份颠簸换来多少收益 | 比较不同基金/策略 |

## 六、新手落地：用最大回撤倒推仓位

一个朴素但有效的框架：

1. 先诚实回答：一只标的浮亏多少我会睡不着 / 会忍不住割肉？（比如 -20%）
2. 再看标的的历史最大回撤。（比如某行业基金历史上最深 -60%）
3. 那么这类标的的仓位上限 ≈ 你能承受的回撤 ÷ 标的历史回撤。（20% ÷ 60% ≈ 1/3 仓位）

**核心思想：仓位 = 自己的风险承受力 ÷ 标的的风险度**，而不是"我看好就多买"。

## 七、与本项目（风险评估工具）的对接

以上所有指标都可以**程序化计算**，输入只需要历史行情/净值序列：

```
历史价格序列 → 日收益率序列 → 标准差 × √250 = 年化波动率
价格序列 → 历史最高点与之后最低点 = 最大回撤
收益序列 + 无风险利率 → 夏普 / 索提诺比率
```

这正是本项目 `stock-investment-risk-assessment` 可以实现的第一个分析模块。
