# 估值指标：PE、PB 与估值分位

> 归档日期：2026-09-22
> 类型：学习笔记（风险与评估）
> 一句话总结：**估值衡量的是"现在的价格贵不贵"——买得太贵本身就是一种风险；而最实用的用法不是绝对数值，是估值分位数。**

## 一、估值解决什么问题

风险衡量的另一面：波动/回撤量的是"过程有多痛"，估值量的是**"入场价有多贵"**。再好的公司，买在泡沫顶点也可能十年不回本——这属于永久损失风险的范畴。估值就是判断当前价格相对内在价值贵不贵的尺子。

## 二、四个基础估值指标

### 1. PE（市盈率）

**公式**：`PE = 股价 / 每股盈利 = 公司市值 / 净利润`

**直觉**：按当前盈利水平，"几年回本"。PE = 20 粗略理解为按现在的赚钱能力 20 年收回投入。

**适用**：盈利稳定的成熟型公司（消费、公用事业等）、宽基指数的整体估值判断。

**不适用**：

- **亏损公司**：盈利为负，PE 无意义。
- **强周期股**（煤炭、钢铁、化工、养殖、航运等）：有反直觉规律——**"高 PE 时买、低 PE 时卖"**。因为低 PE 往往出现在周期顶点（产品价格最高 → 盈利暴增 → PE 显得很低，但盈利即将下滑），高 PE 甚至亏损反而常在周期底部。
- 利润波动大、靠一次性收益撑起利润的公司。

### 2. PB（市净率）

**公式**：`PB = 股价 / 每股净资产 = 公司市值 / 净资产`

**直觉**：花多少钱买 1 块钱的账面资产。PB < 1（"破净"）意味着市值低于账面净资产。

**适用**：银行、券商、保险、地产等**重资产/金融行业**；以及判断大盘指数的极底部区域（历史上A股几次大底，全市场破净股数量激增）。

**不适用**：轻资产公司（品牌、技术、人才才是核心资产，净资产意义小，长期 PB 高是常态）。

### 3. 股息率（Dividend Yield）

**公式**：`股息率 = 过去一年每股分红 / 当前股价`

**直觉**：不靠价差、纯靠分红一年能收回百分之几。高股息通常意味着低估值 + 经营成熟 + 现金流真实（分红是最难造假的信号之一）。指数层面，股息率与国债收益率之差也是判断市场贵贱的参考。

### 4. PEG（市盈率相对盈利增速）

**公式**：`PEG = PE / 盈利增速（%）`

**直觉**：成长股视角——PE 30 但盈利增速 40%（PEG = 0.75），可能并不贵；PE 15 但增速 5%（PEG = 3），可能并不便宜。粗略经验 PEG < 1 为增长未被充分定价。**注意**：依赖对增速的预测，预测错则全错，只适合作为辅助。

## 三、最重要的用法：估值分位数

### 为什么需要分位数

绝对估值高低**没法跨对象比较**：银行常年 PE 5 倍、科技股 30 倍也正常——不同行业盈利模式和成长性完全不同；同一个行业，不同利率环境下"合理估值"中枢也不同。

### 怎么算

**把当前估值放在它自己的历史序列里看位置**：

```
估值分位 = 历史上比当前估值低的天数占比
例：沪深300 当前 PE 处于近10年 25% 分位
   = 过去10年里，只有25%的时间比现在便宜
```

### 经验法则（非铁律）

- **< 30% 分位**：偏低区域，定投可以加速；
- **30%–70%**：中性区域，正常节奏；
- **> 70% 分位**：偏高区域，定投减速、逐步止盈。

分位数是**指数基金定投加减速**最常用的依据之一。

## 四、关键认知：估值是尺子，不是钟

这是新手最容易犯的错——把"便宜"当成"要涨"：

- **低估可以更低**：跌到 10% 分位后还能再跌半年；高估可以更高：70% 分位后还能再涨一年。
- 估值回答的是**"现在买入，长期的安全边际够不够"**（买得便宜，未来即使继续跌，回本所需的涨幅更小），而不是**"什么时候涨"**。
- 择时靠分位很难精确，但**决定"该贪婪还是该恐惧的大区域"**是有效的。

一句话：**用估值决定力度（买多买少），不要用估值赌时点（何时暴涨）。**

## 五、新手落地：两根尺子一起用

评估一只标的"现在能不能买"，建议流程：

1. **回撤尺**（见《风险衡量指标》）：历史最大回撤多少？我承受得起吗？→ 决定仓位上限；
2. **估值尺**：当前估值分位在哪？→ 决定买入节奏（分位低加速、分位高减速）；
3. 行为纪律：分批买入，不一把梭。

## 六、与本项目（风险评估工具）的对接

估值分位数同样完全可以程序化：

```
历史 PE/PB 序列（指数或个股）→ 排序/统计 → 当前值的历史百分位
→ 结合最大回撤 → 输出"仓位建议 × 节奏建议"
```

可与风险指标模块合并为本项目的核心评估流水线。
