# 收益归因：因子分解与资金流向

> 归档日期：2026-09-23
> 背景：原型讨论中提出"量化页面展示涨跌点的判断/预测依据"，引出因子归因概念辨析。
> 结论：因子归因是收益结构分析（值得作为知识理解）；资金流向是市场观测指标（可做事实展示、不做信号）；两者都不做日度涨跌归因——那属于叙事谬误。

## 一、为什么"解释每天涨跌"是个陷阱

市场每日涨跌背后有无数因素，事后挑一个配上"依据"，是行为金融学的**叙事谬误**（narrative fallacy）：制造"市场可解释"的错觉。本项目知识库的根基之一正是"短期不可预测、用纪律替代预测"（见《量化交易入门》《股价的形成机制与羊群效应》）。因此 SIRA 的可解释性边界为：

> **解释自己的纪律（规则为什么触发），不做；解释市场的涨跌（今天为什么跌），更不做。**

## 二、因子归因（Factor Attribution）：收益的统计分解

**它分析的不是"今天为什么涨"，而是"一段时间的收益从哪类风险来"。** 方法：把组合每日收益率对一组因子收益做时间序列回归，得到各因子的暴露（β）与贡献。

示例：某基金今年 +15% →

| 来源 | 贡献 | 含义 |
|---|---|---|
| 市场因子（Beta） | +8% | 市场整体上涨 × 仓位暴露 |
| 规模因子（SMB） | +3% | 小盘风格跑赢的贡献 |
| 动量因子 | +2% | 追涨风格暴露 |
| 价值因子（HML） | -1% | 价值风格拖累 |
| 残差（Alpha） | +3% | 系统性因子解释不掉的部分（"能力"或运气） |

- 经典因子体系：Fama-French 三因子/五因子（市场/规模/价值/盈利/投资）、Carhart 加动量；业界实务为 Barra 风险模型一族（数百个风格/行业因子）。
- 因子收益本身由历史价格构造（如 SMB = 小盘组合收益 − 大盘组合收益），所以说它"基于价格走势"在数据来源上部分正确——但分析对象始终是**收益结构**，不是日度涨跌原因。
- 回答的问题："你赚的钱是不是你应得的？你的超额到底存不存在？"——与夏普比率同族的度量尺。

## 三、资金流向（Money Flow）：另一套东西

大盘/主力/散户/板块"流入流出"属于订单层面的统计推断，与因子归因无涉。三个实情：

1. **"净流入"是统计口径而非真实资金移动**：每笔成交买卖金额必然相等；"净流入" = 主动买方向（吃卖单）成交的累计差。
2. **大单 ≠ 主力**：算法拆单普及后，大单/小单与机构/散户的对应关系已很弱。
3. **预测力弱且衰减快**：资金流指标的短期择时价值在学术证据上很低；境内监管亦收紧此类披露（北向实时流向已停止），可靠性佐证。

## 四、对 SIRA 的取舍（决策记录）

| 项 | 取舍 | 理由 |
|---|---|---|
| 日度涨跌归因（"今天为什么跌"） | ❌ 不做 | 叙事谬误；LLM 日度归因≈编故事；成本高价值负 |
| 涨跌"预测依据"展示 | ❌ 不做 | 与"用纪律替代预测"红线冲突；工具滑向荐股形态 |
| **规则触发依据** | ✅ 做 | 展示"我自己的规则为什么动作"：触发快照 = 规则条件 + 当日实际值（如 PE 分位 24.3% < 30%） |
| **提醒触发依据** | ✅ 做 | 命中的 M4 影响标签链：资讯标题 + 方向 + 强度 + 原文摘录（可回溯） |
| K线资讯事件标注 | ✅ 保持现状 | 标注客观事实（"这天有条利空资讯"），不做因果断言，点击跳转资讯阅读页 |
| 因子归因（工具功能） | ⏸ 一期不做 | 个人组合因子暴露一眼可见（买宽基 = 市场因子）；作为知识已归档本文 |
| 资金流数据 | 🔶 仅事实展示 | akshare 有接口；只做客观信息（如板块涨跌榜），不做信号、不做解读 |
