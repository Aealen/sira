# 量化交易入门

> 归档日期：2026-09-22
> 类型：学习笔记（基础知识）
> 一句话总结：**量化交易 = 把"什么时候买、买多少、什么时候卖"写成明确的数学规则，交给程序执行——我们学的定投和再平衡，其实就是最简单的量化策略。**

## 一、定义

量化交易（Quantitative Trading）：**用数学模型和计算机程序代替人的主观判断来做交易决策与执行**。

主观交易 vs 量化交易的核心区别：

| | 主观交易 | 量化交易 |
|---|---|---|
| 决策依据 | 人的分析、盘感、新闻 | 写成代码的明确规则 |
| 情绪影响 | 恐慌/贪婪常干扰（[羊群效应](股价的形成机制与羊群效应.md)） | 规则面前无情绪 |
| 覆盖广度 | 一个人盯不过来几只 | 程序同时扫全市场几千只 |
| 可验证性 | "感觉有效"无法复现 | 历史数据上可精确回测 |

## 二、和已学知识的关系：你已经接触过量化了

回顾知识库里的策略，会发现它们全是"规则化"的：

- **定投**：`每月X日买入Y元` —— 一条可编程执行的规则；
- **智能定投**：`估值分位<30% 买1.5倍，>70% 暂停` —— 带条件的规则；
- **再平衡**：`股债偏离±5% 触发调仓` —— 一条再明确不过的量化规则；
- **回撤止盈**：`从高点回撤15%卖出` —— 同上。

**把这些规则写成程序自动执行，就是量化交易。** 换句话说：量化不是玄学，是"纪律的代码化"——它正是用机器的纪律性去对抗我们在行为金融学里学到的那些人类偏差。

## 三、量化的三个层级

1. **程序化执行 / 规则策略**（个人完全可行）
   人工设计规则，程序执行或提醒。定投、网格交易（跌X%买一档、涨X%卖一档）、趋势跟踪（如指数跌破200日均线减仓）都属此类。频率：日级、周级。
2. **多因子 / 统计模型**（专业机构与高级个人玩家）
   用统计方法从历史数据中挖掘"因子"（影响收益的特征）：价值因子（低PE）、动量因子（过去强者恒强）、质量因子（高ROE低负债）……按因子打分构建组合，定期调仓。频率：周级到月级。
3. **高频交易 HFT**（机构专属）
   微秒级抢单、套利，拼的是机房距离和硬件。**个人无法参与**，也与我们无关。

## 四、核心方法论：回测与它的陷阱

量化最有力的工具是**回测（Backtest）**：把策略放到过去N年的历史数据上模拟运行，看收益、[最大回撤](../02-风险与评估/风险衡量指标：波动、回撤与夏普比率.md)等表现。

**最大的陷阱是"过拟合"**：规则参数调到在历史上完美，实盘却一塌糊涂——因为那个"完美"只是拟合了历史的噪声，像把答案背下来再去考同一张卷子。防御手段：

- 参数越少越好（简单规则比复杂模型更耐用）；
- 样本外检验（用一半历史调参，另一半历史验证）；
- 逻辑优先（策略先要有经济学/行为学解释，再谈数据验证——比如"低估买入"有逻辑，"周三买入"没有）。

## 五、个人量化的现实约束（A股）

- **T+1**：当天买入次日才能卖——高频思路直接出局；
- **涨跌停板**：极端行情下策略想买卖成交不了；
- **数据与成本**：免费数据（akshare）质量够做研究，不够做专业级实盘；交易手续费会吃掉高频利润；
- **现实定位**：个人适合中低频（周/月级调仓）的规则策略——这恰好是我们工具能支撑的范围。

## 六、我们工具的定位（重要边界）

当前设计的是**辅助决策工具**，不是全自动量化交易系统：

- 数据 → 指标 → 展示 → **人做决策** → 模拟盘执行（练习+验证）；
- 定投计划是"半自动"：规则执行，但只动用虚拟资金。

它同时是通往量化的地基：数据源层、指标库、模拟撮合引擎，这三样加上一个**回测引擎**（把模拟盘的撮合逻辑跑在历史数据上）就构成个人量化系统的雏形——正是二期可以演进的方向。
