# 量化回测详解

> 归档日期：2026-09-22
> 类型：学习笔记（基础知识）
> 一句话总结：**回测 = 把策略规则放到历史数据上"重放"，几秒钟看完十年的"如果当时"——它最大的价值是证伪，最大的陷阱是过拟合。**

## 一、定义与类比

**回测（Backtest）**：把策略规则放到历史数据上模拟执行，生成资金曲线并评估绩效。

类比：历史行情是**录好的棋局**，策略是棋手，回测 = 让棋手对录像重下一遍。不花真钱、不等时间，10 年行情几秒跑完。

## 二、五步流程

1. **数据准备**：历史 K 线 / 基金净值序列；
2. **策略规则**：明确的 if-then（例：估值分位 < 30% → 买入 1.5 倍额度）；
3. **模拟撮合**：按历史价格"假装"成交，扣除手续费；
4. **记账**：逐笔记录买卖、持仓、资金 → 资金曲线（每日账户总值）；
5. **绩效评估**：总收益 / 年化 / 最大回撤 / 夏普 / 胜率（即[风险指标](../02-风险与评估/风险衡量指标：波动、回撤与夏普比率.md)那套）。

## 三、演示实例（本项目第二次代码验证，2026-09-22）

**设定**：构造 250 天"先涨(100→140) → 深跌(140→80) → 修复(80→140)"行情（叠加小幅正弦波动），对比两种规则：

| 参与者 | 规则 | 总收益 | 最大回撤 |
|---|---|---|---|
| 一直持有 | 期初买入全程不动 | +17.9% | **-42.9%** |
| 均线趋势 | 收盘价 > 20日均线持有，跌破空仓 | **+77.5%** | -3.7% |

**两个教学点**：

1. **回测的价值**：同样的行情，不同规则结果天差地别——"如果当时……"从感慨变成可计算的答案；
2. **回测的陷阱（现场版）**：+77.5% 这么漂亮，是因为**数据是我特意构造得趋势干净的**。真实行情充满震荡与假突破，均线策略会被反复打脸。回测结果的漂亮程度，很大程度取决于喂了什么数据、调了多少参数——这就是过拟合。

## 四、三大陷阱（必背）

| 陷阱 | 机制 | 防御 |
|---|---|---|
| **过拟合 / 未来函数** | 参数调到历史最优；规则混入"当时不可能知道的信息"（如用年报数据在年中判断） | 参数最少化；样本内调参、样本外验证 |
| **幸存者偏差** | 只用今天还活着的标的回测，退市的不在样本里 → 收益系统性高估 | 尽量包含退市标的；对结果打折看待 |
| **成本 / 滑点忽略** | 不算手续费、假设收盘价无条件成交 | 按真实费率计费；对流动性差的标的打折假设 |

**元规则**：历史有效 ≠ 未来有效（利率环境、参与者结构会变）。回测结果永远当**下限估计**，不当收益承诺。

## 五、正确姿势

1. **逻辑优先**：策略先要有经济学/行为学解释（"低估买入"有，"周三买入"没有），再看数据；
2. **样本内 / 样本外分割**：一半历史调参、另一半验证，后者才是真实成绩；
3. **参数越少越好**：一个参数的策略比十个参数的耐用；
4. **当证伪工具用**：回测的最大价值是快速淘汰不靠谱的想法，不是证明要发财。

## 六、与 SIRA 的关系（B 档引擎的积木）

回测引擎 = **历史数据（M1 KlineCache，已有）+ 绩效指标（M2 指标库）+ 模拟撮合结算（M3 交易引擎）** 三块积木的串联循环。这也是调研结论"自研轻量回测"的成本依据：零件全是现成计划内的。
