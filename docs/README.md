## 知识地图（学习主线）

```
01 是什么        股票与基金的本质、价格如何形成（含行为金融）
      ↓
02 贵不贵/险不险  风险指标（波动率/最大回撤/夏普） + 估值（PE/PB/分位数）
      ↓
03 怎么操作      配置定比例 → 定投买入 → 再平衡持有 → 分位+回撤止盈
```

每一层都不依赖"预测市场"：01 解释为什么短期不可预测，02 提供客观的度量尺，03 用纪律替代预测。

后续可按主题新增目录，例如：

- `02-风险与评估/`：波动率、最大回撤、估值分位等风险评估方法
- `03-策略与想法/`：定投、资产配置、择时等策略调研与自己的想法
- `04-工具与实现/`：数据分析脚本、风险评估工具的设计与实现记录

## 归档规则

1. 所有文档使用**简体中文**编写。
2. 每篇文档顶部注明**归档日期**，方便回溯知识沉淀的时间线。
3. 一个主题一篇文档，文件名即主题名，便于检索。
4. 对话中讨论出的关键认知、结论，及时整理归档，避免只留在聊天记录里。
5. 文档内容为学习笔记与知识科普，**不构成投资建议**。
