## 三、撮合简化说明（模拟盘边界）

1. **市价单**：以提交时刻实时快照价直接成交（不做订单簿排队与滑点模拟；滑点属于回测二期"三大陷阱"的自查项）
2. **限价单**：挂单等待，快照价触及限价即成交（原型已画挂单列表+撤单弹层）
3. **拒单规则**：非交易时段（9:15 前仅接受预埋单，原型已画示例）、委托价超涨跌幅、违反 T+1（当日买入标的卖出）、零股买入
4. **T+1 实现**：持仓层标记可卖数量 = 昨日及以前买入量
5. **快照延迟**：免费源约 3s 延迟，模拟盘如实采用（不假装实时）
