## 五、技术发现（开发中踩到的坑，供后续参考）

1. **FastAPI 0.141 的 `include_router` 改为惰性挂载**（`_IncludedRouter`）：`app.routes` 遍历不再直接看到子路由，功能正常但旧的验证方式失效——用 curl 真实请求验证路由，别靠遍历 routes。
2. **pandas 3.0.6 + akshare 1.18.96 兼容性未验证**：akshare 历史上对新版 pandas 适配滞后，若后续报错，优先尝试降级 `pandas<3`。
3. **美股全市场快照（`stock_us_spot_em`）体积大、拉取慢**：已在实现中给单独的更长内存 TTL（300s）。
4. Windows + Git Bash 环境下 ZCode 会话无法重命名自己的工作目录（见第一节待办）。
