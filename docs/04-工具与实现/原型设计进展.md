## 二、视觉风格决策（Wise 风格 + 本地化）

- 规范来源：<https://getdesign.md/wise/design-md>，完整规范见同目录 [DESIGN-Wise风格.md](DESIGN-Wise风格.md)
- 核心语言：lime 绿 `#9fe870` 主按钮 / sage 灰绿 `#e8ebe6` 页面底 / 白卡 24px 圆角无阴影（表面对比即层次）
- **本地化调整 1**：中文字体 Noto Sans SC 替代 Wise Sans / Inter
- **本地化调整 2**：行情涨跌遵循中国大陆惯例**红涨 `#d03238` / 绿跌 `#2ead4b`**；Wise 原版语义色（positive 绿 / negative 红）仅用于非行情场景
- **争议决策（待用户确认）**：资讯情绪配色定稿为"利好=淡红、利空=淡绿"（跟随红涨绿跌惯例，中文财经语境常见），与 Wise 原语义色相反

## 三、绘制方式（技术方案）

- 绘制由动态 Workflow 子代理执行，模型 `GLM-5.3-Flash`（用户指定：视觉能力 + 省 token）
- 工作流脚本存于 `.zcode/workflow-drafts/`；规格以自然语言写入 ask，子代理通过 Pen MCP（execute/read_skill/get_app_state/browser/get_style）操作画布
- 已验证：workflow 子代理可访问 Pen MCP 工具；每屏经 Get+visitor 数据层自查（溢出/缺 fill/placeholder）

## 四、技术踩坑（重要）

1. **Pen MCP 服务端渲染缺陷**：TakeScreenshot 与 Export 只渲染顶层节点，子树（文本/icon/path/flex 子 frame）全部丢失——导出 PNG 为纯 sage 底色空白图。三层独立验证坐实（视觉模型分析导出图 / 主会话对照实验 / 字节数相同）。**设计验证以 Pen 应用客户端渲染为准（正常），导出待环境修复**。
2. **.pen 文件落盘**：MCP 修改存在于 Pen 应用活动文档会话，**不自动写盘**——改完必须在 Pen 应用内 Ctrl+S，否则丢稿。
3. pen 的 frame 默认即 flex 横向布局：需要绝对定位子节点时必须显式 `layout:"none"`，否则 x/y 被静默忽略。
4. workflow 的 artifact id 必须编译期字符串字面量；旧 run（无 transcript boundary）不能 Amend 缓存回放，只能新建脚本。
